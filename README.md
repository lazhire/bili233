# bili233 0.10.2

## 名称与图标

本版显示名称为 bili233，使用官方应用条目的粉色图标；包名、签名保持不变，覆盖安装保留数据。非官方应用，图标不包含于源码 MIT 授权，详见 THIRD_PARTY_ASSETS.md。

广告检查结果与可实施方案见 AD_FILTER_FEASIBILITY.md；此版未启用过滤。

## 右上角入口

右上角原全屏按钮改为进入沉浸模式，携带当前网页进入 VR 影院；已在影院时显示退出沉浸模式，返回桌面浏览器。网页播放器自身全屏及菜单中的全屏功能保留。

## 延续改动

- B 站使用一套应用主题 CSS，避免与 WebView 自动暗化叠加。滚动、懒加载、网站类名/行内样式改变时，分批检查新增的 UI 区域并补齐浅色背景和文字；不改卡片网格，不重载页面，不反转图片或视频。其他 HTTPS 网站继续使用 WebView 暗化。
- 网页音量轨道由独立拖动逻辑处理，垂直轨道向上提高、水平轨道向右提高；捕获拖动并拦截拖动结束产生的音量按钮点击，避免提高音量时误切静音。音量大于 0 自动解除静音，0 为静音。可在全屏顶栏的喇叭图标或菜单中使用原生音量滑条与播放/暂停，适合手柄和捏合输入。网页 DOM 若变更，原生滑条仍可使用。
- 主视频第一次开始播放默认有声，音量为 0 时恢复最近的正音量，初始 50%。允许网页有声播放，应用不主动自动播放；网站自身决定是否启动播放。后续主动点击静音或把音量拖到 0 会保留，切换新视频时默认有声。
- VR 主视频播放期间，无明显指向移动或点击约 2.5 秒后隐藏自绘光标及 SDK 光标/射线。移动超过约 5dp 或按下/松开立即恢复，过滤微小抖动。仅关闭光标视觉系统，ISDK 输入始终有效。打开菜单、暂停视频、拖动窗口或显示归中按钮时恢复。
- SDK 默认指向距离 5 米与窗口允许的 8 米范围不匹配，本版显式设置为 20 米，继续同步曲率和输入宽高。
- 声明可选手部追踪及 V2 手部模型，进入影院时按系统权限类型请求手部追踪授权。启用头显设置中的手部追踪、放下手柄：手部射线指向后捏合可点击，捏住后移动可滚动网页或调节原生滑条；近距离可直接触摸。曲面窗口移动仍用手柄握把，当前 SDK 不支持抓取变形曲面窗口，未加入双手缩放窗口。

## 使用

Edge 风格标签页、地址栏与自定义侧栏延续 0.9；最多 6 个标签页，切换时暂停上一页媒体。进入/退出影院重新载入当前页，登录共用。曲率 0–100%，0 为平面，75 为 90°，100 为 120°；握把移动、归中功能保留。

点击全屏顶栏喇叭图标可调节视频音量；设备整体音量仍由头显系统控制。

本版已编译 APK 并覆盖安装到连接的 Quest 3，保留数据。滑条误触、滚动色差、远距离输入和真实手势操作需要在实际佩戴中确认，未运行测试套件。

## 安装与源码

ARM64 / Android API 34 以上。SideQuest 或 adb install -r bili233-0.10.2.apk。沿用原包名与签名，覆盖安装保留登录及设置。

构建需要 JDK 17、Platform 35、Build Tools 35.0.0、Gradle 8.13、Meta Spatial SDK 0.14.0。local.properties 配置 sdk.dir，CINEMA_KEYSTORE 指向此前开发密钥，然后运行 gradlew.bat :app:assembleDebug。源码包不含 SDK、缓存和签名私钥。

手部指向与捏合参考 Meta 官方 Interaction SDK 说明：https://developers.meta.com/vr/documentation/spatial-sdk/spatial-sdk-isdk-overview/
指向范围及权限参考：https://developers.meta.com/vr/documentation/spatial-sdk/spatial-sdk-isdk-gaze/

应用非官方。网页内容、清晰度与播放器能力由网站提供。
