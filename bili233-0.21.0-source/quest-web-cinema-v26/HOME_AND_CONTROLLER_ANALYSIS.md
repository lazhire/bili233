# 0.12.0 首页和手柄交互修正

## 真实网页与 Quest 检查

- 临时无账号浏览器的 B 站首页自动跳转至 /zh-Hans。旧版只识别 /，因此没有启用首页布局。新版支持 /、/zh-Hans、/zh-Hant、/en 及末尾斜杠。
- 真实卡片存在 bili-video-card → bili-feed-card → feed-card → container 两层外包装。旧版会把 feed-card 误标为网格，产生多个嵌套网格。新版找到最外层卡片格子，仅将其父列表作为网格；真实页面 37 张卡片对应一个网格。
- 首页观察器以前会因任意元素增删重新全页查找卡片。现在只检查新增的相关子树，卡片内部动画/计数变化不触发布局扫描。网站删除分类栏后不反复插回，避免与其渲染互相干扰。
- 移除把预取请求返回空内容的拦截，交给 WebView 处理资源加载与缓存。空响应可能影响后续资源复用，这是防御性修正，未证明是之前卡住的唯一原因。
- 保留页面首次可见即结束 native 等待、不按 12 张固定分页、慢封面不隐藏整页的处理。设置提供恢复原网页并重新加载。
- 参考电脑中官方客户端的卡片式分类、两行标题与主题组织，独立实现；不复制其源码或播放器。默认隐藏首页大轮播，可单独恢复；已有明确保存的轮播偏好保留。

## 手柄操作

顶栏播放图标、全屏工具栏音量入口和菜单均可打开底部原生控制面板。视频上方区域保留可见，点击关闭收起面板。

- 进度：72dp 高的触控区域，按住拖动预览时间，松开后一次跳转；取消手势不提交。前后 10 秒按钮方便微调。
- 音量：64dp 高控件，拖动预览百分比，松开应用；−5%/+5% 直接微调。零音量为静音。
- 控件绑定到当前 WebView 和视频资源标识；异步轮询不会覆盖正在拖动的值，换视频后拒绝旧拖动提交。
- 直播等没有可用时间范围时禁用进度；无主视频时禁用播放控制，避免误操作首页预览。支持 seekable 时间段并避开时间段间的空隙。
- 网页快捷静音仍独立于播放器音量。

## 验证

APK 编译通过。临时浏览器回归覆盖卡片数量 0/1/11/12/13/21、广告开关、节点复用、全部广告后追加普通视频、慢封面、语言路由、双层卡片、300 次卡片内部 DOM 增删不触发全页扫描、网站移除分类栏不被反复插回，以及控制接口的跳转边界、音量步进和旧视频标识保护。

已覆盖安装到连接的 Quest 3（保留应用数据），日志确认 WEB_PAGE_FINISHED 和 BROWSER_PAGE_VISIBLE。真机首页 DOM 检查 21 张卡片、2 条明确广告、一个网格，唤醒后视口 1346×771；控制面板截图正常，无相关启动崩溃日志。真实无账号网页检查 37 张卡片、一个网格。

未完成实际佩戴下的手柄拖动、手势捏合、所有视频/直播及长期滚动验证；不保证网络风控或今后网页改版都不会导致加载问题。
